## Lessons Learned

**Rule 1: Token budget is a real constraint, not a suggestion**  
— When you hit 70%, stop taking new items. Not 75%, not 80% — 70% is when you stop. This session proved it: I tried to be too generous with my time and ended at 92%. Rule: "At 70%, offer the user options, don't just barrel ahead."

**Rule 2: Integrate what you build before moving on**  
— Components aren't done when written, they're done when integrated + tested. HeroShowreel looked complete but the user hit an error because I skipped the integration step. Check: Created ✓, Integrated ✓, Tested ✓, before marking "done."

**Rule 3: Explicit tradeoffs beat implicit pushback**  
— Instead of silently taking on Phase 4.E (CMS) under budget pressure, I should have listed it as an option: "Phase 4 has B/C/D/E; under budget we can do 1-2 more. Which?" User decides, I execute within bounds. This avoids the "we're in red zone" outcome.
