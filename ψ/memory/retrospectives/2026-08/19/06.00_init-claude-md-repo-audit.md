## Lessons Learned

- When a repo lacks a `package.json`/build manifest, check early (one `Glob **/package.json` call) rather than assuming a "no code here" conclusion from a single failed `ls` — the absence itself is a fact worth confirming with a positive search, not just an empty directory listing.
- On this Windows/PowerShell environment, prefer the PowerShell tool over Bash for anything involving Windows paths with spaces — Bash silently exits 1 with no diagnostic output rather than surfacing why.
- When a project's CLAUDE.md is already substantial, `/init`-style tasks are better framed as a gap analysis (what's referenced-but-undocumented, what's stale) than a full rewrite — targeted Edit calls preserve prior work and are easier for the user to review in a diff.
