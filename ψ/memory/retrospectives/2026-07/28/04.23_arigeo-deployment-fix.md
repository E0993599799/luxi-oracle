---

## Lessons Learned

**Pattern**: When a component uses framework hooks (like `useLocale()`, `useTranslations()`, `useRouter()`), their providers *must* be set up before the component tree renders. Build success ≠ runtime success.

**Rule for future sessions**: 
- If components import hooks, grep for their provider setup (e.g., `NextIntlClientProvider`, `NextIntlPlugin`)
- If provider is missing, add it to the config layer (middleware + wrapper), not as a band-aid in a single component
- Test with realistic locale switching (navigate to /en, /th URLs) to verify provider is working

**Escalation**: Flag this as a project-init pattern — future arigeo-like projects should include i18n setup in the initial scaffold if they use next-intl hooks.
