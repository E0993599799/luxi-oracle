## Architecture Decisions

1. **Paged Carousel vs. Continuous Scroll**
   - Chose paged carousel (scroll entire page at once, not peek)
   - Controls center-bottom (prev/next circle buttons, dot pagination, pause)
   - Matches Kao reference, simpler interaction model

2. **LatestCarousel Data Loading**
   - Made `items` prop optional, defaults to hardcoded Thai/EN data
   - Uses `useLocale()` hook to detect language
   - Integrates seamlessly with existing `LazyLatestCarousel` wrapper
   - No breaking changes to page.tsx

3. **Media Component for Image Locking**
   - Used existing `Media` component with `ratio` prop
   - 16/9 for FeatureDuo images → eliminates height overflow issues
   - 4/3 for LatestCarousel cards
   - Single source of truth for image rendering

4. **Arigeo Colors in CSS**
   - Red `#D50306`, darkred `#C50C15`, surfaces (beige/blue)

## Lessons Learned

1. **Trust the terminal chain** — WSL2 mounts Windows paths at `/mnt/X/` automatically. Check first, don't assume limitation.

2. **Paged carousels lock aspect ratio** — Using Media with explicit `ratio` props prevents images from stretching the container. The Media wrapper *owns* the height, image *fills* it. No overflow, no surprises.

3. **Lazy-loading wrappers allow component refactoring** — The old LatestCarousel and new one are drop-in compatible via LazyLatestCarousel. Breaking changes in the component don't break the page because the wrapper abstracts the interface.

4. **Bilingual defaults in components** — Add `useLocale()` + hardcoded data inside React components, not in config files. Makes components self-contained and testable.
