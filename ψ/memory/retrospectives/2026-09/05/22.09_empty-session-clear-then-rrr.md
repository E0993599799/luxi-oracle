## Lessons Learned

- When a `/rrr` (or any session-summarizing skill) fires on a session with no
  discernible work, verify via the session .jsonl before writing prose — a retro
  that borrows substance from prior commits/sessions is a rationalization, not a
  reflection, even if it "reads fine."
- Path-encoding logic that replaces `/` and `.` with `-` must also handle spaces
  (and other separators) if the working directory can contain them — test the
  encoding against `ls -d ~/.claude/projects/*<repo>*` rather than trusting the
  regex blindly, especially on Windows-mounted paths (`/mnt/d/...`) which commonly
  have space-containing segments.
- For very small sessions (session .jsonl under ~50 lines), skip the background
  dig-miner subagent and mine timestamps inline — the spawn/wait cost isn't
  justified by a handful of lines.
