## Learning Objectives

### Understanding BEM
- [ ] What is BEM? (Block Element Modifier)
- [ ] Why use BEM? (Consistency, scalability, maintainability)
- [ ] Block vs Element vs Modifier
- [ ] Naming conventions and patterns
- [ ] Real-world examples

### BEM Syntax
- [ ] Block: `.block-name`
- [ ] Element: `.block-name__element`
- [ ] Modifier: `.block-name--modifier`
- [ ] Combined: `.block-name__element--modifier`

### Practical Application
- [ ] How to identify blocks in UI
- [ ] How to identify elements within blocks
- [ ] How to identify modifiers/variations
- [ ] Writing CSS with BEM structure
